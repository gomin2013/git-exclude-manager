Privacy Policyนโยบายความเป็นส่วนตัว

Short version: Git Exclude Manager collects nothing. Your repositories and exclude files stay on your Mac.สรุปสั้นๆ Git Exclude Manager ไม่เก็บข้อมูลใดๆ repository และไฟล์ exclude ของคุณอยู่ในเครื่องของคุณ

Last updatedอัปเดตล่าสุด 2026-10-17

The appตัวแอป

  • No accounts, analytics or tracking. The app has no telemetry, crash reporting or update checks. It does not contact any server of ours, because there isn't one.ไม่มีบัญชีผู้ใช้ ไม่มี analytics ไม่มีการติดตาม แอปไม่มี telemetry ไม่ส่งรายงาน crash และไม่เช็กอัปเดต ไม่ติดต่อเซิร์ฟเวอร์ของเรา เพราะเราไม่มีเซิร์ฟเวอร์
  • Your files stay local. Each .git/info/exclude and its exclude.bak are read and written in place, inside the repository. They never leave your Mac unless you export or send them yourself.ไฟล์อยู่ในเครื่อง .git/info/exclude และ exclude.bak ถูกอ่านและเขียนในที่เดิมภายใน repository และจะไม่ออกจากเครื่อง เว้นแต่คุณ export หรือส่งเอง
  • Settings such as language, appearance and colours, open tabs, recent repositories and the open side panel are stored in macOS user defaults on your Mac.การตั้งค่า เช่น ภาษา ธีมและสี แท็บที่เปิดอยู่ repository ล่าสุด และแผงด้านข้างที่เปิดอยู่ เก็บใน user defaults ของ macOS ในเครื่องคุณ
  • History (your last edits and pinned states) lives in memory while the app is open and is gone when you quit.History (การแก้ไขล่าสุดและสถานะที่ปักหมุด) อยู่ในหน่วยความจำระหว่างที่แอปเปิดอยู่ และหายไปเมื่อปิดแอป
  • Pattern Clipboard lives in memory while the app is open. ⌘C also puts the patterns on the macOS pasteboard, like any copy.Pattern Clipboard อยู่ในหน่วยความจำระหว่างที่แอปเปิดอยู่ การกด ⌘C จะใส่ pattern ลงใน pasteboard ของ macOS ด้วย เหมือนการคัดลอกทั่วไป

AI Agent (optional)AI Agent (ไม่บังคับใช้)

  • AI features do nothing until you choose a provider. Nothing is sent until you send a message or click Generate Comment.ฟีเจอร์ AI ไม่ทำงานจนกว่าคุณจะเลือกผู้ให้บริการ และจะไม่ส่งอะไรจนกว่าคุณจะส่งข้อความหรือกด Generate Comment
  • Chat messages include the repository name and the current content of its .git/info/exclude so the assistant can answer about them. Generate Comment sends only the one pattern you are editing.การแชต จะแนบชื่อ repository และเนื้อหาปัจจุบันของ .git/info/exclude ไปด้วยเพื่อให้ผู้ช่วยตอบได้ตรง Generate Comment ส่งไปเฉพาะ pattern ที่กำลังแก้
  • Apple Foundation Models run on your Mac. Ollama runs on your Mac at 127.0.0.1. With either one, nothing leaves the machine.Apple Foundation Models ทำงานบนเครื่อง Ollama ทำงานในเครื่องที่ 127.0.0.1 ถ้าเลือกสองตัวนี้ ข้อมูลไม่ออกจากเครื่อง
  • OpenAI, Google Gemini and Anthropic Claude receive the request directly from your Mac using your own API key. Their privacy policies apply to that data.OpenAI, Google Gemini และ Anthropic Claude รับคำขอโดยตรงจากเครื่องคุณด้วย API key ของคุณเอง ข้อมูลนั้นอยู่ภายใต้นโยบายความเป็นส่วนตัวของผู้ให้บริการแต่ละราย
  • API keys are stored in your macOS Keychain and are only sent to the provider they belong to.API key เก็บใน Keychain ของ macOS และส่งไปเฉพาะผู้ให้บริการเจ้าของ key นั้น

This websiteเว็บไซต์นี้

  • The site is hosted on GitHub Pages. GitHub may log visits as described in the GitHub Privacy Statement.เว็บไซต์นี้โฮสต์บน GitHub Pages ซึ่ง GitHub อาจบันทึกการเข้าชมตาม GitHub Privacy Statement
  • Pages load icons from unpkg.com, and the Download page asks the GitHub API for the latest version. No cookies, no analytics.หน้าเว็บโหลดไอคอนจาก unpkg.com และหน้า Download ถาม GitHub API เพื่อหาเวอร์ชันล่าสุด ไม่มี cookie ไม่มี analytics
  • Your language choice is saved in your browser's localStorage and never sent anywhere.ภาษาที่เลือกเก็บใน localStorage ของเบราว์เซอร์ และไม่ถูกส่งไปไหน
