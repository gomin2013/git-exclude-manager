Keep local files out of git status. ซ่อนไฟล์ส่วนตัวจาก git status ได้ง่ายๆ

A free macOS app for .git/info/exclude, the ignore file that is never committed. Hide editor folders, notes and secrets without touching your team's .gitignore. แอป macOS ฟรีสำหรับ .git/info/exclude ไฟล์ ignore ที่ไม่ถูก commit ซ่อนโฟลเดอร์ของ editor โน้ตส่วนตัว และไฟล์ลับ โดยไม่ต้องแตะ .gitignore ของทีม

Every repository's exclude file, in one windowไฟล์ exclude ของทุก repository รวมไว้ในหน้าต่างเดียว

Open as many repositories as you like, keep their patterns tidy and move the good ones between them.เปิดได้หลาย repository จัดระเบียบ pattern ให้เป็นหมวดหมู่ แล้วคัดลอก pattern ดีๆ ข้ามไปใช้ repository อื่นได้

Sections you can dragแบ่งหมวดแล้วลากจัดเรียงได้

A blank line becomes a section break with an optional # heading — double-click it to rename. Drag patterns and sections into any order.บรรทัดว่างกลายเป็นตัวแบ่งหมวด ใส่ # หัวข้อได้ ดับเบิลคลิกเพื่อเปลี่ยนชื่อ ลาก pattern และหมวดไปเรียงตรงไหนก็ได้

A tab per repositoryหนึ่งแท็บต่อหนึ่ง repository

Drag tabs to reorder, jump with ⌘1 to ⌘9 or ⌃Tab, drop a folder from Finder to open another. Your tabs come back on relaunch.ลากสลับแท็บได้ กด ⌘1 ถึง ⌘9 หรือ ⌃Tab เพื่อสลับ ลากโฟลเดอร์จาก Finder มาวางเพื่อเปิดเพิ่ม เปิดแอปใหม่แท็บก็ยังอยู่

Space turns patterns on or off, ⌫ deletes, Return edits, ⌥⌘1–7 opens a side panel.Space เปิด/ปิด pattern ⌫ ลบ Return แก้ไข ⌥⌘1–7 เปิดแผงด้านข้าง

Copy patterns between repositoriesคัดลอก pattern ข้าม repository

⌘-click or ⇧-click patterns, press ⌘C, switch tabs and paste. Only the missing ones are added. Pattern Suggestions lists what your other repositories ignore, one click each — both live in the side panel.กด ⌘ หรือ ⇧ แล้วคลิกเลือก pattern กด ⌘C สลับแท็บแล้ววาง เพิ่มเฉพาะตัวที่ยังไม่มี ส่วน Pattern Suggestions แสดง pattern ที่ repository อื่นใช้ กดเพิ่มได้ในคลิกเดียว ทั้งสองอยู่ในแผงด้านข้าง

Safe by designออกแบบมาให้ปลอดภัย

A small helper does the file work, and every save takes the same five steps.helper ตัวเล็กเป็นผู้จัดการไฟล์ และทุกการบันทึกผ่าน 5 ขั้นตอนเดิมเสมอ

  1. Check the repositoryตรวจ repository

    Only folders with a real .git are accepted. Anything else is refused.รับเฉพาะโฟลเดอร์ที่มี .git จริงเท่านั้น นอกนั้นปฏิเสธทั้งหมด

  2. Keep every lineเก็บทุกบรรทัดไว้

    Lines you didn't touch, including git's default header, stay exactly as they were.บรรทัดที่ไม่ได้แก้ รวมถึง header เริ่มต้นของ git ยังอยู่เหมือนเดิมทุกตัวอักษร

  3. Back upสำรองไฟล์

    The previous version is kept next to it as exclude.bak.เวอร์ชันก่อนหน้าเก็บไว้ข้างๆ เป็น exclude.bak

  4. Write atomicallyเขียนแบบ atomic

    A crash in the middle of a save can't leave a half-written file.แม้เครื่องค้างระหว่างบันทึก ไฟล์ก็ไม่เสียครึ่งๆ กลางๆ

  5. Go backย้อนกลับได้

    History steps back through this session's edits; Repository › Restore Previous brings back the last save, even after a relaunch.History ย้อนการแก้ไขในรอบนี้ได้ทีละขั้น ส่วนเมนู Repository › Restore Previous คืนการบันทึกล่าสุดได้แม้เปิดแอปใหม่

Exclude files belong to you, so the helper runs as you, never as root. It can only touch files you could already edit, and the app never asks for an administrator password.ไฟล์ exclude เป็นของคุณเอง helper จึงรันด้วยสิทธิ์ของคุณ ไม่ใช่ root แตะได้เฉพาะไฟล์ที่คุณแก้ได้อยู่แล้ว และแอปไม่เคยขอรหัสผ่านผู้ดูแลระบบ

AI Agent

Ask about your ignore patternsถามเรื่อง pattern ได้เลย

Chat with an assistant that sees this repository's exclude file — watch it work step by step, read its thinking, and copy the patterns it suggests.คุยกับผู้ช่วยที่เห็นไฟล์ exclude ของ repository นี้ ดูขั้นตอนการทำงานและความคิดของโมเดล แล้วคัดลอก pattern ที่แนะนำไปใช้ได้เลย

  • Answers stream in with live steps and seconds, the model's thinking (Ollama, Claude, Gemini), Markdown with copyable code blocks, and a Stop button.คำตอบค่อยๆ แสดงพร้อมขั้นตอนและเวลา เห็นความคิดของโมเดล (Ollama, Claude, Gemini) แสดงผลแบบ Markdown พร้อมปุ่มคัดลอก code และกดหยุดได้
  • One-click questions like “Suggest patterns this repository should ignore” or “Are any of my patterns redundant?”คำถามสำเร็จรูป เช่น “แนะนำ pattern ที่ repository นี้ควร ignore” หรือ “มี pattern ซ้ำซ้อนไหม?” กดได้ในคลิกเดียว
  • Generate Comment explains a pattern in a few words. Only that pattern is sent.Generate Comment อธิบาย pattern สั้นๆ ให้ ส่งไปเฉพาะ pattern นั้น
  • Switch models right in the panel. API keys stay in your Keychain, and Apple Intelligence or Ollama keep everything on your Mac.เปลี่ยนโมเดลได้ในแผงเลย API key เก็บใน Keychain เลือก Apple Intelligence หรือ Ollama ถ้าอยากให้ทุกอย่างอยู่ในเครื่อง
  • The AI never edits the file. Every change goes through you.AI ไม่แก้ไฟล์เอง ทุกการเปลี่ยนแปลงต้องผ่านคุณ
