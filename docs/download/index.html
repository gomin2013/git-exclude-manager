Install in three stepsติดตั้ง 3 ขั้นตอน

  1. 1. Move it to Applications1. ย้ายไปไว้ที่ Applications

    Open the .dmg and drag Git Exclude Manager into Applications. Run it from there, not from the disk image, so the helper can be registered.เปิดไฟล์ .dmg แล้วลาก Git Exclude Manager ไปที่ Applications เปิดแอปจากตรงนั้น ไม่ใช่จาก disk image เพื่อให้ลงทะเบียน helper ได้

  2. 2. Allow the first launch2. อนุญาตให้เปิดครั้งแรก

    This build isn't notarized yet, so macOS blocks it once. Click Done on the warning, open System Settings, Privacy & Security, and click Open Anyway. Or run this in Terminal:build นี้ยังไม่ได้ notarize macOS จึงบล็อกครั้งแรก กด Done ที่คำเตือน เปิด System Settings แล้วไปที่ Privacy & Security กด Open Anyway หรือรันคำสั่งนี้ใน Terminal

    xattr -dr com.apple.quarantine "/Applications/GitExcludeManager.app"

  3. 3. Allow the helper3. อนุญาต helper

    If macOS asks, allow Git Exclude Manager in System Settings, General, Login Items & Extensions. It runs as your user, so no administrator password is needed.ถ้า macOS ถาม ให้อนุญาต Git Exclude Manager ใน System Settings แล้วไปที่ General, Login Items & Extensions helper รันด้วยสิทธิ์ผู้ใช้ของคุณ จึงไม่ต้องใช้รหัสผ่านผู้ดูแลระบบ

Build from sourceBuild จากซอร์สโค้ด

Swift Package Manager only, no Xcode project. You need Xcode 16 or later. Apps you build yourself aren't quarantined, so there is no Gatekeeper prompt.ใช้ Swift Package Manager อย่างเดียว ไม่มี Xcode project ต้องมี Xcode 16 ขึ้นไป แอปที่ build เองจะไม่ถูก quarantine จึงไม่มีคำเตือนจาก Gatekeeper

git clone https://github.com/gomin2013/git-exclude-manager.git
cd git-exclude-manager
scripts/build-app.sh
cp -R build/GitExcludeManager.app /Applications/

See theดูรายละเอียดเพิ่มเติมใน README.

Uninstallถอนการติดตั้ง

Turn the helper off in Login Items & Extensions, then move Git Exclude Manager to the Trash. Every .git/info/exclude stays exactly as you last saved it, with its exclude.bak next to it.ปิด helper ใน Login Items & Extensions แล้วย้าย Git Exclude Manager ลงถังขยะ ไฟล์ .git/info/exclude ทุกไฟล์จะคงอยู่ตามที่บันทึกไว้ล่าสุด พร้อม exclude.bak อยู่ข้างๆ

To clear the app's settings too:ถ้าต้องการล้างการตั้งค่าของแอปด้วย

defaults delete com.gitexcludemanager.app
