About

Git Exclude Manager
Version 0.1.0 (Prototype)
Manage your .git/info/exclude files visually.
Patterns are ignored locally only and never committed.
Built with Swift + SwiftUI · macOS 14+

Help
➕
Add a Pattern
Click Add to create a new ignore pattern. Patterns support glob syntax (e.g. *.log, build/).
🔘
Enable / Disable
Click the circle toggle on each row to enable or disable a pattern without deleting it.
⠿
Reorder Patterns
Drag the ⠿ handle on the left of each row to reorder. Drag is disabled while the search box is active.
👁
Preview Raw File
Click the 👁 Preview Raw button to see the exact content that will be written to .git/info/exclude.
✨
AI Generate Comment
When adding or editing a pattern, enter a pattern name and click ✨ AI Generate to auto-fill a contextual comment.
